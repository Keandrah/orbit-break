ORBIT BREAK is a fast-paced minimal browser survival game built from one prompt. Dodge falling red shards, catch cyan stars to boost your score, and survive for 30 seconds.

Open `game.html` in any modern web browser to play.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
